## ターゲット層

２５ − ３９歳までの SNES、ゲームボーイ、
ロクヨン、プレステ、PSP 等を

経験されてきたゲーム経験者の方

家庭あり、お子様が５歳 − １０歳くらいと仮定して、
当時を懐かしむと共にお子様とも当時のゲームお話など
で盛り上がれるようにしています。

抽象的・範囲が広すぎると NG。性別が違うだけでも UI やアプローチは変わるし、年代が違うともっと変わる。
ペルソナを作ると具体化しやすいのでオススメ

### ターゲット層の理由

自分自身が経験してきた世代だから
横のつながりで情報収集がしやすい
この世代は各ゲーム業界が革新的な技術でもって様々な
革新的なハード、ゲームを提供してきた背景があるからこそ
ユーザーのゲームへの知見が深い分、ユーザーの経験と
自分の経験とがマッチした分ユーザーのことを考えて
アプリ作りができるため

なぜそのターゲット層なのか、理由があると説得力が増す
ただしイメージだけで書くと調査不足が露見するので必要あればある程度の調査は必要

### ユーザー獲得方法

まずは X コミュニティにて MVP 的な立ち位置で作成、拡散
レビューを頂きつつ改善していきます。

しかし、ユーザー層が限定されるため、
X 内のゲームコミュニティなどへの働きかけ、
忘年会シーズン、年末年始の帰省に合わせて
お酒のつまみにという切り口でも告知する予定

TIKTOK Youtube ショートでも実際に使ったものを
紹介していきます

基本的に受動的なものはまず入ってこないと思ったほうがよい。
能動的に動いて獲得する方法を書くべし。
受動的なものにする場合は、どのような戦略があるか書くと良いかも。
